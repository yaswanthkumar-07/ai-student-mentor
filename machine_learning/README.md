# Machine Learning workspace

| Folder | Purpose |
|---|---|
| `datasets/` | Training CSVs (kept separate from the app demo data in `/data`) |
| `notebooks/` | Jupyter exploration notebooks |
| `preprocessing/` | Reusable cleaning and feature code |
| `training/` | Training scripts that write to `saved_models/` |
| `saved_models/` | Serialized models (git-ignored) |

No models are trained in the foundation batch.
